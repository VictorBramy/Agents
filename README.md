# 🎯 Smart Job Hunter AI Agent (סוכן מציאת עבודה אישי)

סוכן AI אוטונומי לאיתור משרות הייטק מותאמות אישית בישראל, מבוסס ניתוח קורות חיים ודרישות מעסיקים, עם דשבורד מקומי לניהול ומעקב.

---

## 🌟 יכולות מרכזיות

1. **ניתוח עמוק של קורות חיים (CV Profiler)**:
   - קורא קבצי **PDF** או טקסט חופשי.
   - מחלץ באופן אוטומטי: תפקידי יעד (Target Roles), סטאק טכנולוגי (Skills), רמת ניסיון (Junior / Mid / Senior), ושנות ניסיון.
   - פועל עצמאית באמצעות מנוע מקומי מובנה, עם אפשרות שילוב Gemini API לניתוח סמנטי מורכב.

2. **סריקה מתמדת של משרות הייטק בישראל**:
   - **Greenhouse ATS**: סורק משרות פתוחות מלוחות דרושים של חברות מובילות בישראל (Wiz, monday.com, Snyk, AppsFlyer, Gong, Riskified ועוד).
   - **Comeet ATS**: סורק משרות מחברות סטארטאפ ויוניקורנים מקומיים (Lemonade, BigPanda, WalkMe, SimilarWeb ועוד).
   - **LinkedIn Jobs**: חיפוש משרות הייטק בישראל לפי תפקידי היעד של המועמד.
   - **הוספה ידנית (Manual Add)**: אפשרות להדביק כל משרה מקבוצות וואטסאפ או פייסבוק ולקבל עליה ניתוח AI מיידי.

3. **התאמת AI וציון התאמה (Match Scoring)**:
   - חישוב ציון התאמה מ-0 עד 100% לכל משרה.
   - סימון כישורים חופפים (Matching Skills) וכישורים חסרים (Missing Skills).
   - הסבר מנומק בעברית מדוע המשרה מתאימה למועמד ומה כדאי להדגיש.

4. **מחולל מכתבי פנייה מותאמים אישית (Cover Letter Generator)**:
   - יצירת מכתב פנייה / פוסט פנייה ממוקד למגייסים (בעברית או באנגלית) המבליט את ההישגים והכלים הרלוונטיים מתוך קורות החיים של המועמד.
   - כפתור העתקה מהירה ללוח (1-Click Copy).

5. **דשבורד ווב מקומי מתקדם (Local Web Dashboard)**:
   - ממשק מודרני מבוסס Tailwind CSS עם תמיכה מלאה בעברית (RTL).
   - מעקב אחר סטטוס מועמדות (חדש, שמור, הוגשה מועמדות, ראיון, נדחה).
   - כל הנתונים נשמרים מקומית במסד נתונים **SQLite** פרטי ומאובטח במחשב שלך (`data/jobs.db`).

6. **סוכן טיסות זולות רב-מנועי (Multi-Engine AI Flight Hunter)**:
   - איתור הטיסות הזולות ביותר מנתב"ג (TLV) באמצעות סריקה מקבילה ב-**Kiwi.com** (האקר פייר ושילובי חברות לואוקוסט) וב-**Google Flights**.
   - הצלבת מנועים חכמה עם קישורים ישירים ל-**Skyscanner**, **Kayak**, **Momondo**, ו-**Skiplagged**.
   - תמיכה מלאה בהנחיות טקסט חופשי בעברית באמצעות **Google AI Gemini**.
   - השוואת מחירים ויזואלית (Chart.js), ניתוח כבודה (טרולי, תיק אישי ומזוודה), וקישור הזמנה ישיר לכל מנוע.
   - זמין בכתובת: `http://127.0.0.1:8080/flights` או דרך הכפתור בסרגל העליון.

## 🚀 הפעלה מהירה

### שיטה 1: לחיצה כפולה (מומלץ)
הפעל את הקובץ **`run.bat`** בתיקיית הפרויקט. הדפדפן ייפתח אוטומטית בכתובת:
`http://127.0.0.1:8080`

### שיטה 2: הרצה משורת הפקודה
```bash
python main.py
```
ונווט בדפדפן אל: [http://127.0.0.1:8080](http://127.0.0.1:8080)
